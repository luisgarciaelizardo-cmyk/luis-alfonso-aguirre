# Lic. Luis Alfonso Aguirre — Agente de seguros

Sitio web de una sola página (HTML + CSS, sin dependencias de compilación).

- `index.html` — la página.
- `assets/img/` — logo, foto principal, aseguradoras y publicaciones de Instagram.
- `assets/video/` — video de presentación y su portada.

Para verlo, abre `index.html` en el navegador. Para publicarlo gratis, activa
GitHub Pages en *Settings → Pages* (rama `main`, carpeta raíz).
